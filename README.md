# homelab-service-template

Template repository for new `homelab-*` service repositories.
Intended to be cloned directly when starting a new homelab service.

Canonical standards live in the sibling repository `homelab-standards`.

Agent-facing documentation is vendored into `imported/` by sync scripts and is not committed.

Services must be declared in `homelab-infra/registry.yaml` before they are exposed.

Vendored standards are generated by scripts in homelab-standards and do not require Bash or WSL.
